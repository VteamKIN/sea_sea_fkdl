## 用户需求

1. **处理流程重构**：将二值化和边线检测移到逆透视变换之后执行
2. **图像尺寸更新**：原图160*128，逆透视后图像数组160*128，但有效区域为160*80
3. **检测框参数更新**：x:36-124, y:18-62
4. **角点检测逻辑**：确保角点检测时边线未被填补，丢线判断仅在检测框内生效
5. **保留边线填补功能**：用于控制模块使用，但需延迟到角点检测之后

## 核心修改点

- 调整 `img_process()` 主函数处理流程顺序
- 修改逆透视变换函数直接从原图读取灰度值
- 新增/修改二值化函数适配逆透视图像
- 修改边线检测函数适配逆透视图像尺寸
- 修改丢线检测范围限制在检测框内
- 延迟 `edge_fill()` 执行时机

## 技术方案

### 处理流程调整

**当前流程**：

```
memcpy → Get_imgOSTU → cbh_img_process → edge_fill → calc_road_width → calc_midline → WarpPerspective → detect_lost → detect_corner → detect_road
```

**新流程**：

```
memcpy → WarpPerspective(原图→逆透视灰度) → Get_imgOSTU_warp → cbh_img_process_warp → calc_road_width → calc_midline → detect_lost(检测框内) → detect_corner → edge_fill → detect_road
```

### 关键技术决策

1. **逆透视变换**：从 `mt9v03x_image` 直接读取灰度值到 `warp_image`，遍历范围为 `WARP_IMAGE_H (80)`

2. **二值化处理**：新增函数在 `warp_image` 上进行大津法二值化

3. **边线检测适配**：修改 CBH 系列函数使用 `WARP_IMAGE_W` 和 `WARP_IMAGE_H` 作为图像尺寸

4. **丢线检测范围限制**：`detect_lost()` 仅扫描 `y: start_point_y → end_point_y`

5. **删除 `WarpBoundaryPoints()`**：因为边线已在逆透视坐标系计算，不再需要坐标变换

### 数据流说明

- `imgGray[128][160]`：存储原图灰度数据（仅用于拷贝过渡）
- `warp_image[128][160]`：逆透视后图像（有效区域80行）
- `left_boundary/right_boundary/center_line[128]`：边线数组（逆透视坐标系）
