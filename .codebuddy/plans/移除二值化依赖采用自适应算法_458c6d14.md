## 用户需求

1. **移除二值化算法**：删除所有涉及大津法(OTSU)和CBH算法的实现部分及相关逻辑
2. **采用自适应算法**：完全使用自适应边线检测算法（`zi_shi_ying_warp()`）
3. **功能正常**：确保去除二值化后代码功能仍能正常运行

## 核心功能

- 逆透视变换后的图像通过自适应局部阈值进行边线检测
- 路口检测改为使用自适应局部阈值判断黑白跳变
- 简化图像处理流程，减少计算开销

### 需要删除的变量

- `histogram[256]`, `gray_min`, `gray_max` - 直方图相关
- `minThreshold`, `maxThreshold`, `minGrayscale`, `maxGrayscale` - OTSU参数
- `nowThreshold`, `oldThreshold` - 阈值变量
- `cbh_White_Tallst_Point`, `cbh_White_Point_Width`, `cbh_bai_dian_max`, `cbh_bai_dian_min`, `cbh_threshold` - CBH变量
- `imgGray[IMG_H][IMG_W]`, `image_gray`, `image` - 原图灰度缓冲

### 需要修改的函数

#### `detect_road()` - 路口检测

**当前逻辑**（依赖二值化图像）：

```c
if(warp_image[left_y][left_x] == Black && warp_image[left_y + 1][left_x] == White)
```

**修改为自适应局部阈值**：

```c
int local_thres = 计算block_size窗口内均值 - clip_value;
if(warp_image[left_y][left_x] < local_thres && warp_image[left_y + 1][left_x] >= local_thres)
```

#### `img_process()` - 主函数流程

**新流程**：

```
WarpPerspective() → zi_shi_ying_warp() → calc_road_width() → calc_midline() → 
detect_lost() → detect_corner() → edge_fill() → detect_road_adaptive() → detect_road_type()
```

### 保留的核心功能

1. **自适应算法**：`zi_shi_ying_warp()`, `findline_lefthand_adaptive()`, `findline_righthand_adaptive()`
2. **逆透视变换**：`WarpPerspective()`, `Transform_Point1()`, `Transform_Point2()`
3. **边线后处理**：`edge_fill()`, `calc_road_width()`, `calc_midline()`
4. **道路识别**：`detect_lost()`, `detect_corner()`, `detect_road_type()`
5. **关键数据**：`warp_image`, `left_boundary`, `right_boundary`, `center_line`
