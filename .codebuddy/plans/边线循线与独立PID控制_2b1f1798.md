## 产品概述

优化智能车控制系统，实现基于道路类型的自适应循线策略，区分直线和转弯状态并使用独立PID参数。

## 核心功能

- **道路类型识别**：识别直道、左弯、右弯三种道路类型
- **偏差计算优化**：采样区域上移至前方区域，根据道路类型自动选择循线边线
- **双PID控制**：直线状态和转弯状态使用独立的PID参数组
- **状态自适应**：根据道路类型自动切换PID参数和控制策略

## 循线策略

| 道路类型 | 循线方式 | 偏差计算 |
| --- | --- | --- |
| 直道 | 循中线 | center_line前方区域 - 图像中心 |
| 左弯 | 循右边线 | right_boundary前方区域 - 图像中心 |
| 右弯 | 循左边线 | left_boundary前方区域 - 图像中心 |


## 技术栈

- 基于现有TC2xx平台和C语言
- 保持当前的逆透视变换和边线跟踪算法
- 复用现有的状态机框架

## 实现方案

### 1. 道路类型识别

基于边线拐点位置判断：

- 无拐点 → 直道
- 左拐点靠前 → 左弯
- 右拐点靠前 → 右弯

### 2. 偏差计算

采样前方区域（y=20~50），根据道路类型选择边线：

```c
switch(road_type) {
    case ROAD_STRAIGHT: 循 center_line
    case ROAD_LEFT_CURVE: 循 right_boundary
    case ROAD_RIGHT_CURVE: 循 left_boundary
}
```

### 3. 双PID参数

```c
// 直线PID（响应温和）
float kp_straight = 15.0f;
float ki_straight = 0.0f;
float kd_straight = 8.0f;

// 转弯PID（响应快速）
float kp_turn = 25.0f;
float ki_turn = 0.0f;
float kd_turn = 12.0f;
```
