## 产品概述

优化智能车图像处理模块的边线跟踪与道路识别算法，实现完整且连续的边线检测功能，同时优化处理性能。

## 核心功能

- 改进边线存储方式：从一维数组改为二维数组坐标点列表存储，支持存储完整的L形、直角弯等复杂边线
- 优化跟踪算法：基于现有的左右手自适应跟踪函数，实现方向感知的边线跟踪
- 同步优化道路识别函数：detect_corner、detect_road、detect_road_type 适配新的边线数据格式
- 性能优化：分析并优化性能瓶颈，将处理时间从7-9ms降低到3-5ms
- 边线绘制优化：确保边线只绘制一个像素点
- 解决断线和追踪不完整问题，能够准确捕捉直角弯道的完整边线轮廓

## 技术栈

- 基于现有TC2xx平台和C语言
- 保持当前的逆透视变换和自适应阈值策略
- 复用已有的左右手跟踪函数框架

## 核心问题分析

### 当前存储方式的限制

```c
int16 left_boundary[WARP_IMAGE_H];   // left_boundary[y] = x
```

- 每行只能存储一个x坐标
- 无法表示水平边线（同一y，多个x点）
- L形边线的水平段无法完整记录

### 性能瓶颈分析（7-9ms）

**瓶颈1：WarpPerspective() 逆透视变换**

- 双重循环：80×124 = 9920次迭代
- 每次调用 Transform_Point1() 进行浮点矩阵运算
- **预估耗时：2-4ms**

**瓶颈2：zi_shi_ying_warp() 自适应检测**

- 每行遍历2次找 max_gray/min_gray
- 每行遍历1次找道路位置
- 每行搜索左右边界
- **预估耗时：2-4ms**

**其他函数**：calc_road_width(), calc_midline(), edge_fill() 耗时较少（<1ms）

## 解决方案

### 1. 新增边线点二维数组存储

```c
#define MAX_EDGE_POINTS  200

// 左手边线点列表
int16 left_edge[MAX_EDGE_POINTS][2];   // [i][0]=x, [i][1]=y
int16 left_edge_count;                  // 实际点数

// 右手边线点列表
int16 right_edge[MAX_EDGE_POINTS][2];  // [i][0]=x, [i][1]=y
int16 right_edge_count;                 // 实际点数

// 拐点标记
int16 left_corner_index;   // 左边线拐点位置（-1表示无拐点）
int16 right_corner_index;  // 右边线拐点位置（-1表示无拐点）
```

### 2. 性能优化方案

**2.1 WarpPerspective() 优化（推荐：LUT查找表）**

预计算坐标映射表，运行时只需查表：

```c
// 初始化时计算
static int16 warp_lut_x[WARP_IMAGE_H][WARP_IMAGE_W];
static int16 warp_lut_y[WARP_IMAGE_H][WARP_IMAGE_W];

// 运行时只需查表
warp_image[i][j] = mt9v03x_image[warp_lut_y[i][j]][warp_lut_x[i][j]];
```

**预计提速：50-70%**

**2.2 zi_shi_ying_warp() 优化**

合并多次遍历，一次遍历中同时计算max/min和道路位置：

```c
for (int x = 0; x < WARP_IMAGE_W; x++) {
    int gray = AT_IMAGE(&img_raw, x, y);
    // 同时更新max/min和道路边界
    if (gray > max_gray) max_gray = gray;
    if (gray < min_gray) min_gray = gray;
    if (gray > adaptive_thres_estimate) {
        // 更新道路边界...
    }
}
```

**预计提速：30-40%**

**2.3 添加耗时统计**

```c
uint32 warp_time;      // 逆透视变换耗时
uint32 edge_time;      // 边线检测耗时
uint32 total_time;     // 总耗时
```

### 3. 拐点检测策略

跟踪过程标记 + detect_corner() 综合验证：

1. 跟踪过程中方向突变（转90度）时记录拐点索引
2. detect_corner() 综合利用：索引 + 丢线 + 中线突变 + 斜率突变

### 4. 数据转换

将边线点列表转换为逐行边界数组，保持兼容性。

### 5. 边线绘制优化

确认seekfree.c中的边线绘制只使用一个像素点。

## 实现要点

### 性能考虑

- 边线点数限制在200以内
- 使用CPU1数据RAM存储（已配置）
- LUT查找表避免浮点运算
- 合并遍历减少内存访问
- 添加耗时统计定位瓶颈

### 抗干扰能力

- 保持自适应阈值策略
- turn计数限制为8，允许跟踪直角弯
- 多种拐点检测方法相互验证

### 兼容性

- 保留原有的边界数组供控制模块使用
- 后续处理模块无需修改
